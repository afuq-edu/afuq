# /add-files · إضافة ملفات للموقع

## أين يذهب كل ملف

| النوع | المسار |
|---|---|
| سبورات الدروس | `<صف>/<مادة>/board/lesson-boards.pdf` |
| أسئلة السبورة الصفية | `<صف>/<مادة>/board/classroom-board-questions.pdf` |
| ملخصات بالصور | `<صف>/<مادة>/recap/lesson-summaries.pdf` |
| خريطة ذهنية / ملخص درس | `<صف>/<مادة>/summaries/<وحدة>-<درس>-m.pdf` و `-s.pdf`، والكل `all.pdf` |
| العرض التفاعلي | `<صف>/<مادة>/view/slides/index.html` (أو `interactive/`، `lessons/`) |
| صفحة الألعاب | `<صف>/<مادة>/games/index.html` |
| ألعاب ونشاط الدرس | `q/<صف>/<مادة>/index.html` (من `build_quiz.py`) |
| حزم SCORM لنور | `scorm/<صف>/<مادة>/L01.zip` … (من `build_scorm.py`، حزمة لكل درس بنفس ترتيب q/) |

الصف رقم من 1 إلى 12، والمادة بأسماء المجلدات الموجودة (`math`, `science`, `arabic`, `english`, `islamic`, `social`, `it`, `arts`, `pe`, `physics`, `chemistry`, `biology`, `envsci`, `advmath`, `basicmath`). مادة جديدة: اسم إنجليزي قصير بحروف صغيرة، واذكره للمالك.

## الخطوات

1. افتح فرعًا من `main` المحدَّث (مثل `claude/add-<صف>-<مادة>`).
2. ضع الملفات في مساراتها أعلاه، بأسماء إنجليزية بلا مسافات. لا تغيّر أسماء ملفات موجودة: الموقع الرئيسي يربط إليها.
3. قبل الإضافة: أي PDF أكبر من 5 MB مرّره على `python3 tools/pdf_shrink.py <الملف> --apply` (انظر `/shrink-pdfs`).
4. افحص:
   ```bash
   python3 tools/check_site.py
   ```
   يجب ألا تبقى أخطاء، وأن يبقى الحجم الكلي تحت 1 GB. إن تجاوز، توقّف وأخبر المالك بالأرقام واقترح `/shrink-pdfs`.
5. إن أضفت دروسًا لمادة لها حزم SCORM: عدد الحزم يجب أن يساوي عدد دروس `q/`. الفحص ينبّه إن لم يكن، ويمكن مراجعة حزمة بـ `python3 tools/scorm_inspect.py scorm/<صف>/<مادة>/L01.zip`.
6. ارفع وافتح طلب دمج يذكر: ما أُضيف (صف/مادة/أقسام)، الحجم المضاف والحجم الكلي الجديد، ونتيجة الفحص. لا تدمج.
7. ذكّر المالك إن كانت صفحة المادة في الموقع الرئيسي (`afuq-edu.github.io`) تحتاج رابطًا للملفات الجديدة.
