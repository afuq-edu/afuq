# /check-site · فحص الموقع

الأداة `tools/check_site.py` (Python بلا مكتبات خارجية) تفحص الملفات التي ستُنشر (المتتبَّعة في git والجديدة غير المتجاهَلة) في ثوانٍ:

- **الحجم**: المجموع مقابل حد GitHub Pages (1 GB): خطأ فوق 100%، تنبيه فوق 90%، والملفات الأكبر من 10 MB.
- **الروابط**: كل `src`/`href` نسبي في ملفات HTML يشير إلى ملف موجود (الروابط التي تبدأ بـ `/` للموقع الرئيسي فتُتجاوز).
- **صفحات الألعاب q/**: `window.QZ` صالح، `g`/`s` يطابقان المسار، لكل درس عنوان وأسئلة، ونسخة المحرك `?v=` موحّدة.
- **حزم SCORM**: الحزمة تُفتح، `imsmanifest.xml` سليم (SCORM 1.2، identifier `afuq-<صف>-<مادة>-L##`)، الملفات المذكورة موجودة، الترقيم L01..Ln متصل ومساوٍ لعدد الدروس، وكل حزمة تفتح درسها بنفس أسئلة صفحة q/ (غير قديمة).
- **الأسماء**: حروف إنجليزية وأرقام و `-` فقط، لا ملفات فارغة، والملفات المتطابقة.

## الخطوات

1. من جذر المستودع:
   ```bash
   python3 tools/check_site.py
   ```
   لجزء واحد: `--only size,links,q,scorm,names`. للقائمة كاملة بلا اختصار: `--json`. لاعتبار التنبيهات أخطاء: `--strict`.
2. لخّص للمالك بالعربية في سطور قليلة: الحجم ونسبته من 1 GB، ثم الأخطاء (هذه تمنع النشر)، ثم أهم التنبيهات مجمّعة (مثلًا «13 صفحة ألعاب لمادة تقنية المعلومات بلا حزم SCORM» بدل سردها).
3. لكل خطأ اقترح الإصلاح:
   - الحجم فوق الحد → المهارة `/shrink-pdfs`.
   - حزمة قديمة أو ناقصة أو صفحة QZ معطوبة → تُعاد من سكربتات المستودع الرئيسي `afuq-edu.github.io` (`tools/build_quiz.py`، `tools/build_scorm.py`)، لا بالتعديل اليدوي هنا.
   - رابط مكسور أو اسم غير آمن → أصلحه هنا إن كان الملف غير مولَّد، وإلا في المولّد.
4. لا تعدّل ولا تحذف شيئًا ضمن هذه المهارة إلا إذا طلب المالك الإصلاح.

الفحص نفسه يعمل تلقائيًا على GitHub لكل طلب دمج (`.github/workflows/check-site.yml`).
