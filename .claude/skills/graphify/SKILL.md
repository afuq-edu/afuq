# /graphify · خريطة مستودع ملفات أفق

تصنع الأداة `tools/graphify.py` (Python بلا مكتبات خارجية) صفحة HTML واحدة مستقلة، عربية RTL، بالوضعين الفاتح والداكن، ومناسبة للهاتف. تقرأ الملفات المتتبَّعة في git (ما يُنشر على GitHub Pages في `afuq-edu.github.io/afuq/`)، وتأخذ أسماء الصفوف والمواد من صفحات `q/<صف>/<مادة>/index.html` (`window.QZ`)، وتعرض:

- بطاقات: الملفات والمجلدات، الحجم الكلي ونسبته من حد 1 GB، الصفوف، مواد الصفوف، دروس الألعاب، السبورات، الملخصات بالصور، ملخصات الدروس، العروض التفاعلية، صفحات الألعاب، حزم SCORM.
- شريط لكل مجلد رئيسي من حد 1 GB: أخضر تحت 70%، برتقالي حتى 90%، أحمر فوقه.
- جدول تغطية المواد: لكل صف ومادة عدد الملفات في كل قسم (`board`, `recap`, `summaries`, `view`, `games`, `q`, `scorm`).
- شجرة المشروع بعناصر `<details>` (صف ← مادة ← قسم)، وجدول السكربتات بأول سطر من شرحها، وجدول أنواع الملفات.
- ملاحظات: تجاوز الحد، ملفات أكبر من 10 MB، ملفات مكررة بالمحتوى، أقسام ناقصة في مادة بينما أغلب مواد صفها فيها هذا القسم، ألعاب q/ بلا حزمة SCORM أو العكس، أسماء غير مرتبة.

## الخطوات

1. حدّث المستودع دون أي تعديل:
   ```bash
   git fetch origin
   git merge --ff-only origin/main
   ```
   إن فشل الدمج (تعديلات محلية أو تفرّع) فلا تعدّل شيئًا: أكمل على النسخة الحالية واذكر ذلك.
2. شغّل الأداة من جذر المستودع، واكتب الصفحة في مجلد مؤقت خارج المستودع (مجلد scratchpad في الجلسة):
   ```bash
   python3 tools/graphify.py <مجلد-مؤقت>/graphify.html
   ```
   الخيار `--limit-gb 0` يلغي حد المساحة فتُحسب النسب من الحجم الكلي.
3. أرسل الصفحة للمالك ملفًا مرفقًا.
4. لخّص له بالعربية في سطور قليلة:
   - الأرقام الرئيسية (الملفات، الحجم ونسبته من 1 GB، الصفوف، المواد، الدروس، حزم SCORM)،
   - أي مجلد أو ملف كبير، أو اقتراب الحجم الكلي من الحد أو تجاوزه،
   - أي شيء ناقص أو غير مرتب من قسم «ملاحظات» في الصفحة.
5. لا تنشر الصفحة ولا ترفعها إلى أي مستودع إلا إذا طلب المالك ذلك.
