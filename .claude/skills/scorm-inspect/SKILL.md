# /scorm-inspect · فحص حزم SCORM

كل حزمة `scorm/<صف>/<مادة>/L##.zip` فيها: `imsmanifest.xml` (SCORM 1.2، درجة الإتقان 50) و`index.html` (محرك الألعاب مع بيانات كل دروس المادة في `window.QZ`، و`QZ.l` = رقم الدرس الذي تفتحه الحزمة) و`fonts/`.

## الخطوات

1. اعرض الحزمة أو مجلد مادة كاملًا:
   ```bash
   python3 tools/scorm_inspect.py scorm/8/arabic/L02.zip
   python3 tools/scorm_inspect.py scorm/8/arabic/
   ```
   تطبع: العنوان، identifier، الإصدار، درجة الإتقان، الملفات وأحجامها، الدرس الذي تفتحه وعدد أسئلته، استدعاءات SCORM (`LMSInitialize`، `cmi.core.score.raw`…)، ومطابقة الدرس لصفحة `q/`.
2. لتجربتها في المتصفح: `--extract <مجلد-مؤقت>` ثم افتح `index.html` (بلا منصة نور لن تُحفظ الدرجة، وهذا طبيعي).
3. اشرح للمالك بالعربية ما وجدت. أسباب شائعة لمشاكل نور:
   - `imsmanifest.xml` ليس في جذر الـ zip، أو يذكر ملفًا غير موجود.
   - الحزمة قديمة (أسئلتها تختلف عن `q/`) → أعد توليدها بـ `tools/build_scorm.py` في المستودع الرئيسي.
   - رفع مجلد المادة كاملًا بدل حزمة درس واحدة.
4. لفحص كل الحزم دفعة واحدة: `python3 tools/check_site.py --only scorm`.
